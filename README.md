# trueforge-hunt-skills

Agent skills for the TrueForge bug-hunting fleet.

- `skills/foundry-poc` — build forge PoCs that prove exploit impact on a pinned fork block (green-or-it-didnt-happen).
- `skills/hunt-doctrine` — scope-first, seam-diff, dupe doctrine, execution gates.

Import each via TrueForge: Settings -> Skills -> Import from GitHub, repo URL https://github.com/wemightnotmakeit/trueforge-hunt-skills, path skills/<name>, ref main.
